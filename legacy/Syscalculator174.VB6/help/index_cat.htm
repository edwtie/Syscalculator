Manual de Syscalculator 1.74

Introduccio

Syscalculator 1.74 es la linia classica de Syscalculator basada en Visual Basic 6. Aquesta versio mante disponible el flux de treball antic mentre es desenvolupa Syscalculator 2.0.

La versio 1.74 es una versio de manteniment. Inclou correccions per a Windows modern, fitxers de conversio classics i monedes historiques de l'euro, incloent adopcions recents com Croacia 2023 i Bulgaria 2026.

Important: el runtime de Visual Basic 6 es antic i Microsoft ja no el mante activament. Syscalculator 1.74 s'ofereix com a versio legacy. Per a treball nou i funcions futures s'esta preparant Syscalculator 2.0.

Com convertir un valor

  1. Trieu un conversor de la llista.
  2. Escriviu el valor al primer camp.
  3. Llegiu el resultat al segon camp.
  4. Useu la direccio inversa si voleu calcular en sentit contrari.

Exemple: si el conversor seleccionat es de quilometres a milles, escriviu el nombre de quilometres al primer camp. Syscalculator calcula el resultat i el mostra al segon camp. Si activeu la direccio inversa, podeu usar el mateix conversor per tornar de milles a quilometres.

Camps i edicio

  • Copiar copia el text seleccionat del camp actiu.
  • Retallar copia i elimina el text seleccionat.
  • Enganxar insereix text del porta-retalls al camp actiu.
  • Eliminar elimina el text seleccionat.
  • Seleccionar-ho tot selecciona tot el valor del camp actiu.

Si no hi ha text seleccionat, les accions que necessiten una seleccio poden estar desactivades. Aixo evita esborrar o copiar un camp complet per accident.

WizardExpress

WizardExpress converteix valors copiats al porta-retalls. Esta pensat per a programes antics d'Office i Word i per a text simple.

  1. Copieu els valors al porta-retalls.
  2. Obriu WizardExpress.
  3. Executeu la conversio.
  4. Enganxeu el resultat de nou a l'aplicacio.

Nota de compatibilitat: LibreOffice s'ha provat i funciona correctament. Microsoft 365 / Office 365 no funciona de manera fiable amb aquesta integracio VB6 antiga del porta-retalls.

Consell: despres d'executar WizardExpress, enganxeu immediatament el resultat amb Ctrl+V. En Excel modern, el menu contextual d'enganxar pot canviar una altra vegada el contingut del porta-retalls.

Configuracio

  • Podeu canviar l'idioma i la moneda/conversor predeterminat.
  • Podeu iniciar Syscalculator amb Windows.
  • Podeu usar la safata del sistema.
  • Podeu mantenir la finestra sempre visible.
  • Podeu ajustar decimals i format de sortida per a resultats numerics.

Els ajustos es desen als fitxers de configuracio classics. En instal.lacions modernes tambe es copien a la carpeta de dades de l'usuari per evitar problemes de permisos a Windows.

Fitxers NOD i catalegs

Els conversors es desen com a fitxers NOD. El cataleg agrupa aquests fitxers perque apareguin a la llista principal. Si s'afegeixen o es corregeixen fitxers NOD, torneu a obrir Syscalculator o recarregueu el cataleg per veure'ls.

La versio 1.74 conserva els conversors classics de distancia, massa, pressio, temperatura, volum, text i monedes historiques de l'euro.

Limitacions conegudes

  • Aquesta es una aplicacio legacy VB6, no una aplicacio moderna .NET.
  • El runtime VB6 es obligatori.
  • Microsoft 365 / Office 365 pot comportar-se malament amb el porta-retalls.
  • Windows 11 ha estat provat. Windows antics son objectius historics i no sempre es tornen a provar.

Suport i futur

Syscalculator 1.74 conserva la compatibilitat historica. Syscalculator 2.0 es la nova linia moderna, pensada per reduir els riscos del runtime VB6 antic i per afegir funcions noves.
