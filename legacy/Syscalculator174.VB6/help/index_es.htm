Manual de Syscalculator 1.74

Introduccion

Syscalculator 1.74 es la linea clasica de Syscalculator basada en Visual Basic 6. Esta version mantiene disponible el antiguo flujo de trabajo mientras se desarrolla Syscalculator 2.0.

La version 1.74 es una version de mantenimiento. Incluye correcciones para Windows moderno, archivos de conversion clasicos y monedas historicas del euro, incluyendo adopciones recientes como Croacia 2023 y Bulgaria 2026.

Importante: el runtime de Visual Basic 6 es antiguo y ya no esta mantenido activamente por Microsoft. Syscalculator 1.74 se ofrece como version legacy. Para trabajo nuevo y funciones futuras se esta preparando Syscalculator 2.0.

Como convertir un valor

  1. Elija un conversor en la lista.
  2. Escriba el valor en el primer campo.
  3. Lea el resultado en el segundo campo.
  4. Use la opcion de direccion inversa si quiere calcular en sentido contrario.

WizardExpress

WizardExpress convierte valores que se copian al portapapeles. Esta pensado para programas antiguos de Office y Word y para texto simple.

  1. Copie los valores al portapapeles.
  2. Abra WizardExpress.
  3. Ejecute la conversion.
  4. Pegue el resultado de nuevo en la aplicacion.

Nota de compatibilidad: LibreOffice se ha probado y funciona correctamente. Microsoft 365 / Office 365 no funciona de forma fiable con esta integracion VB6 antigua del portapapeles.

Configuracion

  • Puede cambiar idioma y moneda/conversor predeterminado.
  • Puede iniciar Syscalculator con Windows.
  • Puede usar la bandeja del sistema.
  • Puede mantener la ventana siempre visible.

Soporte y futuro

Syscalculator 1.74 conserva la compatibilidad historica. Syscalculator 2.0 es la nueva linea moderna, pensada para reducir los riesgos del runtime VB6 antiguo y para anadir funciones nuevas.
