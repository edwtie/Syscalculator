Manual de Syscalculator 1.74

Introduccion

Syscalculator 1.74 es la linea clasica de Syscalculator basada en Visual Basic 6. Esta version mantiene disponible el antiguo flujo de trabajo mientras se desarrolla Syscalculator 2.0.

La version 1.74 es una version de mantenimiento. Incluye correcciones para Windows moderno, archivos de conversion clasicos y monedas historicas del euro, incluyendo adopciones recientes como Croacia 2023 y Bulgaria 2026.

Importante: el runtime de Visual Basic 6 es antiguo y ya no esta mantenido activamente por Microsoft. Syscalculator 1.74 se ofrece como version legacy. Para trabajo nuevo y funciones futuras se esta preparando Syscalculator 2.0.

Como convertir un valor

  1. Elija un conversor en la lista.
  2. Escriba el valor en el primer campo.
  3. Lea el resultado en el segundo campo.
  4. Use la opcion de direccion inversa si quiere calcular en sentido contrario.

Ejemplo: si el conversor seleccionado es de kilometros a millas, escriba el numero de kilometros en el primer campo. Syscalculator calcula el resultado y lo muestra en el segundo campo. Si activa la direccion inversa, puede usar el mismo conversor para volver de millas a kilometros.

Campos y edicion

  • Copiar copia el texto seleccionado del campo activo.
  • Cortar copia y elimina el texto seleccionado.
  • Pegar inserta texto del portapapeles en el campo activo.
  • Eliminar elimina el texto seleccionado.
  • Seleccionar todo selecciona todo el valor del campo activo.

Si no hay texto seleccionado, las acciones que necesitan una seleccion pueden estar desactivadas. Esto evita borrar o copiar un campo completo por accidente.

WizardExpress

WizardExpress convierte valores que se copian al portapapeles. Esta pensado para programas antiguos de Office y Word y para texto simple.

  1. Copie los valores al portapapeles.
  2. Abra WizardExpress.
  3. Ejecute la conversion.
  4. Pegue el resultado de nuevo en la aplicacion.

Nota de compatibilidad: LibreOffice se ha probado y funciona correctamente. Microsoft 365 / Office 365 no funciona de forma fiable con esta integracion VB6 antigua del portapapeles.

Consejo: despues de ejecutar WizardExpress, pegue inmediatamente el resultado con Ctrl+V. En Excel moderno, el menu contextual de pegado puede cambiar otra vez el contenido del portapapeles.

Configuracion

  • Puede cambiar idioma y moneda/conversor predeterminado.
  • Puede iniciar Syscalculator con Windows.
  • Puede usar la bandeja del sistema.
  • Puede mantener la ventana siempre visible.
  • Puede ajustar decimales y formato de salida para resultados numericos.

Los ajustes se guardan en los archivos de configuracion clasicos. En instalaciones modernas tambien se copian a la carpeta de datos del usuario para evitar problemas de permisos en Windows.

Archivos NOD y catalogos

Los conversores se guardan como archivos NOD. El catalogo agrupa esos archivos para que aparezcan en la lista principal. Si se anaden o corrigen archivos NOD, vuelva a abrir Syscalculator o recargue el catalogo para verlos.

La version 1.74 conserva los conversores clasicos de distancia, masa, presion, temperatura, volumen, texto y monedas historicas del euro.

Limitaciones conocidas

  • Esta es una aplicacion legacy VB6, no una aplicacion moderna .NET.
  • El runtime VB6 es obligatorio.
  • Microsoft 365 / Office 365 puede comportarse mal con el portapapeles.
  • Windows 11 ha sido probado. Windows antiguos son objetivos historicos y no siempre se vuelven a probar.

Soporte y futuro

Syscalculator 1.74 conserva la compatibilidad historica. Syscalculator 2.0 es la nueva linea moderna, pensada para reducir los riesgos del runtime VB6 antiguo y para anadir funciones nuevas.
