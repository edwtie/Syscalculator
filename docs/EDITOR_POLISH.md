# NOD Editor UI polish

De NOD Editor is opgefrist richting een Notepad++-achtige indeling.

## Verbeteringen

```text
Toolbar bovenaan
Statusbar onderaan
Line/column indicator
Lines indicator
UTF-8 indicator
CRLF/LF indicator
Schonere gutter
Consolas editor font
Dirty indicator in titel (*)
SplitContainer voor testpaneel
Testpaneel tonen/verbergen
Voorbeeldtemplates in menu Tools
```

## Nog niet zoals Notepad++

```text
geen syntax highlighting
geen echte tabs voor meerdere bestanden
geen code folding
geen zoek/vervang-dialog
geen minimap
```

Die onderdelen kunnen later worden toegevoegd.
