# Main dialog classic options

De echte converterdialoog is uitgebreid zodat hij beter aansluit op de simulator-preview.

Toegevoegd:

```text
Digit group checkbox
Decimals checkbox
NumericUpDown voor aantal decimalen
Trace knop
format-opties laden vanuit NOD format
```

Gedrag:

```text
format ##.00 -> Decimals aan, waarde 2
Digit group -> toont duizendtallen
Decimals uit -> afronden op hele getallen
```
