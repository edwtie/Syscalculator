# Classic Syscalculator look polish

Deze versie brengt het hoofdvenster dichter bij de oude Syscalculator/Syscalculcator-look.

## Aangepast

```text
klassieke menubalk: File / Edit / Config / Tools / About
converterdeel in GroupBox
optionsdeel in GroupBox
klassiek Windows-grijs
blauwe labels zoals oude converterstijl
menu-items voor copy/paste/clear
config-menu voor Digit group / Decimals / Live convert
introductie opnieuw tonen
```

## Doel

Niet exact VB6 kopiëren, maar de moderne C# WinForms-versie visueel en functioneel dichter bij de oude 1.72-ervaring brengen.
