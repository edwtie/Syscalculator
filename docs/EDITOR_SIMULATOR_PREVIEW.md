# NOD Editor simulator preview

Toegevoegd aan de live preview:

```text
technische live preview
simulator preview
```

## Doel

De simulator preview laat niet alleen metadata zien, maar ook een klein voorbeeldvenster van de converter zoals de eindgebruiker die ongeveer ziet.

## Wat wordt getoond

```text
URLN / Name als venstertitel
klassieke menu- en toolbar-indruk
indoprint/indoend introductietekst
input1 en input2 labels
symb1/symb2/symb3/symb4 op voorbeeldwaarden
format -> decimalen-indicatie
voorbeeld-output op basis van test input
```

## Opmerking

Het is een **simulator** in de editor; geen volledige runtime-converter. Het doel is dat de ontwikkelaar meteen ziet of de NOD-regels logisch en visueel kloppen.
