# Compact classic converter dialog

De echte converterdialoog is compacter gemaakt, dichter bij oude Syscalculator.

## Aangepast

```text
kleiner venster
minder lege ruimte
vaste dialoogstijl
Vooruit/Terug-knoppen uit hoofdbeeld verwijderd
radio buttons blijven voor richting
Enter blijft rekenen
Live convert blijft optioneel
Trace blijft als kleine knop
```

## Reden

De oude Syscalculator had vooral een compacte converterdialoog met radiobuttons.
Grote actieknoppen rechts maakten de nieuwe UI te groot en minder klassiek.
