# Old model converter look

Deze versie bouwt het hoofdvenster veel dichter bij het oude Syscalculator-model.

## Aangepast

```text
compact venster
File / Edit / Config / Tools / About
toolbarframe met 3 iconen links
File-combobox rechts in toolbarframe
radiobuttons links
input1/input2 onder elkaar
geen zichtbare Vooruit/Terug-knoppen
Digit group / Decimals / aantal decimalen onderaan
klassiek grijs Windows-gevoel
```

## Werking

```text
Enter in input1 = vooruit
Enter in input2 = terug
radio bepaalt actieve richting
Live convert bestaat nog, maar is standaard verborgen
Calculator stuurt waarde naar actief veld
```
