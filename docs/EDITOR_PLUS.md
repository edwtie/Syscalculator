# NOD Editor Plus

EditorPlus voegt toe:

```text
tabbladen voor meerdere .nod-bestanden
syntax highlighting
zoek/vervang venster
toolbar met iconen
statusbar met regel/kolom
line-number gutter per tab
testpaneel
```

## Syntax highlighting

Eenvoudige highlighting voor:

```text
NOD commands
math functions
constants
numbers
comments
```

## Zoek/vervang

Nieuwe form:

```text
FindReplaceForm.cs
```

Ondersteunt:

```text
zoek volgende
vervang huidige
alles vervangen
hoofdlettergevoelig aan/uit
```
