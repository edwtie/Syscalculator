# Editor simulator devtool fix

De simulator is aangepast naar een betere ontwikkelingstool.

## Wijzigingen

```text
introductie is niet meer in het convertervenster ingebouwd
introductie staat los via Weergave > Introductie preview
live preview en simulator kunnen verborgen worden
dubbelklik op paneelkop met × verbergt paneel
simulator lijkt meer op echte converter
input1 en input2 staan onder elkaar
symbolen worden niet dubbel getoond
layout gebruikt splitters en is flexibeler
```

## Waarom

`indoprint` hoort bij een losse introductiedialoog vóór de converter start.
Het hoort niet als tekstvak in het convertervenster zelf.
