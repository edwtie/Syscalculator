Syscalculator Installer Return Codes

Last updated: 2026-05-18

Syscalculator production installers are EXE installers built with Inno Setup. The production installer is self-contained and does not download files during installation.

Microsoft Store install command

Use this command for unattended Microsoft Store validation:

Syscalculator-2.0-production-2.0.2026.05.18.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /RESTARTEXITCODE=3010

Successful install

EXE return code value
0
Documentation URL
https://www.tiedragon.com/install/exit-codes.html#0
Meaning
The installer completed successfully and no reboot was requested.

EXE return code value
5
Documentation URL
https://www.tiedragon.com/install/exit-codes.html#5

The user cancelled during the installation phase.

Application already exists

EXE return code value
1638
Documentation URL
https://www.tiedragon.com/install/exit-codes.html#1638
Meaning
A production installation of Syscalculator is already registered on the device. This is a Syscalculator-specific compatibility code.

Another installation is already in progress

EXE return code value
1618
Documentation URL
https://www.tiedragon.com/install/exit-codes.html#1618

4

Reboot required

EXE return code value
3010
Documentation URL
https://www.tiedragon.com/install/exit-codes.html#3010
Meaning
The installer completed but requested a restart. This value is enabled by the /RESTARTEXITCODE=3010 install argument.

Network failure and miscellaneous failure

EXE return code value
1
Documentation URL
https://www.tiedragon.com/install/exit-codes.html#1
Meaning
The production installer is self-contained, but Syscalculator uses network access for update checks and update downloads. Network, update-feed, and miscellaneous failures are treated as a general failure.

Detailed miscellaneous install failure scenarios

EXE return code value
3 for the Partner Center miscellaneous scenario. Additional detailed setup codes are listed below.
Documentation URL
https://www.tiedragon.com/install/exit-codes.html#3
Meaning
Use the detailed return code table below for setup initialization failures, preparation failures, installation failures, cancellation, existing installation, concurrent installation, and reboot-required outcomes.

Detailed return code reference

Network access is used by Syscalculator update checks and update downloads. If a network or update-feed failure must be represented as an EXE return code, use 1.

Return code Meaning
0 Setup completed successfully.
1 Setup failed to initialize.
2 The user cancelled before the actual installation started.
3 A fatal error occurred while preparing to install.
4 A fatal error occurred during installation.
5 The user cancelled during installation.
6 The setup process was forcefully terminated by the Inno Setup debugger.
7 Setup determined that installation cannot proceed.
8 Setup determined that installation cannot proceed until the system is restarted.
1618 Another installation is already in progress.
1638 Syscalculator production is already installed.
3010 Installation completed and a reboot is required.

The standard Inno Setup exit codes are documented by Inno Setup at https://jrsoftware.org/ishelp/topic_setupexitcodes.htm.
