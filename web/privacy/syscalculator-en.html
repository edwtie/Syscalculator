Syscalculator Privacy Statement

Last updated: May 17, 2026

This privacy statement applies to Syscalculator, published by Edward Tie / Tiedragon.

Short Summary

Syscalculator is a desktop application. Calculations, conversions, NOD files and settings are normally processed locally on your computer. Syscalculator does not sell personal data and does not use advertising or analytics tracking.

Syscalculator only contacts Tiedragon or GitHub when you send feedback yourself or when an online update check is used.

What Data Does Syscalculator Process?

Locally on Your Computer

Syscalculator may store local data needed to use the application, such as:

  • application settings;
  • selected language;
  • recent files;
  • update channel and update status;
  • NOD files that you create or open.

This data remains on your own computer unless you choose to share it.

Feedback

If you use the feedback form, the information you enter is sent to Tiedragon:

  • feedback type;
  • name, if you enter one;
  • e-mail address, if you enter one;
  • subject;
  • message text.

You can also choose to include support information. This helps understand an issue and may include:

  • product name and version;
  • release channel;
  • build date;
  • language file;
  • current converter or feature;
  • operating system;
  • .NET version;
  • processor architecture.

The feedback server may also process the IP address. This is used for delivery, troubleshooting and basic rate limiting against misuse. Feedback may be forwarded by e-mail to Tiedragon and, if the host allows it, stored as a protected server copy.

Updates

When Syscalculator checks for updates, the application may download an update manifest from tiedragon.com. The server may receive technically necessary data such as IP address, time of request and standard server log data. Update files may also be provided through GitHub or tiedragon.com.

How Is Data Used?

Data is used to:

  • make Syscalculator work;
  • save local settings;
  • answer feedback or support requests;
  • improve Syscalculator and fix issues;
  • provide updates.

Sharing With Third Parties

Tiedragon does not sell personal data. Data may only be processed by technical service providers needed for hosting, e-mail, downloads or software distribution, such as the web host, GitHub or Microsoft Store.

Retention

Local data remains until you delete it or remove Syscalculator. Feedback messages are kept no longer than necessary for support, troubleshooting and administration. Server logs are retained according to the hosting provider settings.

Security

Feedback and update data are sent over HTTPS when the default Tiedragon endpoints are used. Feedback copies on the server are protected against direct web access where the host supports this.

Your Choices

You can:

  • send feedback without entering a name;
  • turn off support information in the feedback form;
  • disable automatic update checks or change the update channel;
  • remove local files and settings yourself.

Contact

For privacy or data processing questions, contact info@tiedragon.com.
