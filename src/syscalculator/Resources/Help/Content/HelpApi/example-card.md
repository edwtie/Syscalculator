# Voorbeeldkaart

Gebruik dit vooral in NOD-commandopagina's.

Een losse kaart:

```html
<div class="example-card">
  <h3>[help.example.title]</h3>
  <pre>Name Voorbeeld
input1 Waarde
input2 Resultaat
end</pre>
</div>
```

Meerdere kaarten naast elkaar:

```html
<div class="example-grid">
  <div class="example-card">
    <h3>[help.example.one.title]</h3>
    <p>[help.example.one.text]</p>
  </div>
  <div class="example-card">
    <h3>[help.example.two.title]</h3>
    <p>[help.example.two.text]</p>
  </div>
</div>
```
