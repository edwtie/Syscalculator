# Code

## Codeblok

Gebruik `<pre>` voor meerdere regels code:

```html
<pre>Name Celsius naar Fahrenheit
input1 Celsius
input2 Fahrenheit
math ans * 1,8
math ans + 32
end</pre>
```

In NOD-help komt de kopieerknop automatisch door `nod-copy-buttons.js`.
In gewone `main` help is er geen automatische kopieerknop.

## Kleine Code In Een Zin

Gebruik `<code>` voor een command of kort codewoord:

```html
<p>[help.example.text] <code>Name</code>.</p>
```
