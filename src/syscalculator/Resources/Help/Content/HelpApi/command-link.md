# Link Naar Een NOD-Command

Gebruik dit alleen in NOD-help.

```html
<a class="cmd-link" href="nodpage:cmd:math"><code>math</code></a>
```

Vervang `math` door bijvoorbeeld:

```text
name
input1
input2
trans
chg
end
```

Voorbeeld in een zin:

```html
<p>[help.example.text] <a class="cmd-link" href="nodpage:cmd:math"><code>math</code></a>.</p>
```
