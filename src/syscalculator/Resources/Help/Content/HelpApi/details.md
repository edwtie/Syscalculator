# Uitklapblok

Een uitklapblok is handig voor extra uitleg.
De gebruiker kan het open- en dichtklappen.

```html
<details>
  <summary>[help.example.summary]</summary>
  <p>[help.example.details]</p>
</details>
```

Open vanaf het begin:

```html
<details open>
  <summary>[help.example.summary]</summary>
  <p>[help.example.details]</p>
</details>
```

Hiervoor is geen JavaScript nodig.
