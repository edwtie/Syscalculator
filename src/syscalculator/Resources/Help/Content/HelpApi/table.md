# Tabel

Gebruik een tabel alleen als vergelijken duidelijker is dan tekst.

```html
<table>
  <tr><th>[help.table.command]</th><th>[help.table.meaning]</th></tr>
  <tr><td><code>Name</code></td><td>[help.table.name_meaning]</td></tr>
  <tr><td><code>input1</code></td><td>[help.table.input1_meaning]</td></tr>
</table>
```

Tip:

- Houd cellen kort.
- Gebruik liever een lijst als de tabel te breed wordt.
