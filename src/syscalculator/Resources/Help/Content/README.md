# Help Content

Deze map bevat de help-pagina's.

Voor schrijvers:

- Lees eerst [WRITER_GUIDE.md](WRITER_GUIDE.md).
- Gebruik [WRITER_TOOLS.md](WRITER_TOOLS.md) voor de losse help-API groepen.
- Gebruik [WRITER_TEMPLATE.html](WRITER_TEMPLATE.html) als voorbeeld.
- Gebruik [WRITER_TOOLBOX.html](WRITER_TOOLBOX.html) om losse blokken te kopieren.
- De echte helpbestanden staan in `main` en `nod`.

Kort:

- HTML bepaalt de vorm van de pagina.
- `.lng` bestanden bevatten de tekst per taal.
- `[tekst.naam]` verwijst naar tekst in een `.lng` bestand.
- `{NodEditorScreenshot}` en vergelijkbare stukken worden door het programma ingevuld.
