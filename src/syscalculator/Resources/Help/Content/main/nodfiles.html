Syscalculator converters are stored as NOD files. A NOD file describes the name, labels and conversion rules for one converter.

Daily use

  • Open NOD: load a specific converter file.
  • Reload converter list: refresh the list after converter files were added or changed.
  • Catalog manager: inspect and manage the converter catalog.

Editing and compatibility

Use the NOD Editor to create, inspect or repair converter files. Syscalculator 2.0 keeps the classic NOD 1.0 style recognizable, while the editor also explains newer NOD 2.0 features.

Old Syscalculator 1.74 NOD files should remain readable. When a file uses old commands such as input1 and input2, the editor can explain the modern equivalent.
