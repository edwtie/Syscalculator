The input and output fields behave like normal Windows edit fields. The active field is the field that currently has the text cursor or selection.

Editing fields

  • Cut / Copy / Delete work on the selected text in the active field.
  • Paste inserts clipboard text into the active field.
  • Select all selects the complete active field. After that, Copy, Cut or Delete applies to the whole value.
  • Copy input copies the full first field when it has text.
  • Copy output copies the full second field when it has text.
  • Clear fields empties both fields.

The right-click menu shows the same practical edit actions. Syscalculator hides unused Windows IME entries for normal European input languages. For Chinese, Japanese and Korean input, Windows keeps its own IME menu so those input methods still work.

Clipboard commands

  • Ctrl+X: cut selected text.
  • Ctrl+C: copy selected text.
  • Ctrl+V: paste clipboard text.
  • Ctrl+A: select all text in the active field.
  • Del: delete the selection or the next character.
