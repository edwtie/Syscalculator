WizardExpress is the quick clipboard mode. It is meant for users who want to copy values, convert them quickly, and paste them back without opening the advanced editor.

  1. Copy values to the clipboard.
  2. Open WizardExpress.
  3. Click OK.
  4. Paste the converted values back with Ctrl+V, or use the paste menu in applications other than Excel.

Excel / Microsoft 365: Excel has its own clipboard management. Paste immediately with Ctrl+V after WizardExpress. On Windows 10/11, Win+V can open clipboard history so you can pick the converted item manually. See Applications for the Excel details.
