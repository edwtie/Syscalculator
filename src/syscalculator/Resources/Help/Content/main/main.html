The main window is the normal converter screen. The selected converter decides what the first and second fields mean.

  1. Choose a converter from the list at the top.
  2. Type the source value in the first field.
  3. Press Enter, or use live convert when it is enabled.
  4. Read the converted value in the second field.

When Reverse direction is enabled, Syscalculator swaps the meaning of the fields so you can convert back.

If the converter contains an introduction, Syscalculator can show it when the converter is first opened. Use Tools > Show introduction again when you want to reread it.
