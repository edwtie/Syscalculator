The Config menu contains the daily behavior settings for Syscalculator.

  • Reverse direction: swaps the converter direction, including input and output fields.
  • Show introductions: shows or hides converter introduction text when a converter has one.
  • Start with Windows: starts Syscalculator automatically when Windows starts.
  • Always on top: keeps Syscalculator, WizardExpress, and Calculator above other windows.
  • Minimize to tray: hides Syscalculator in the system tray instead of leaving it on the taskbar.
  • Language: changes the interface language.
  • Live convert: converts while you type instead of waiting for a separate action.
  • Catalog manager: manages the converter catalog.

Use Tools > Show introduction again when you want to reread the introduction for the current converter.
