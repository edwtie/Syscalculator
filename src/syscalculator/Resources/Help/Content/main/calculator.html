The calculator is for quick arithmetic while you are working with a converter. It can place the calculated result directly in the active input or output field.

  1. Click in the field where the result should go.
  2. Open Tools > Calculator, or use the calculator button.
  3. Calculate the value.
  4. Insert or copy the result back into Syscalculator.

For converter formulas, NOD files and educational formula cards, use the NOD Editor instead of the simple calculator.
