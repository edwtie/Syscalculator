The window settings control how Syscalculator stays available while you work in other programs.

Window and tray

  • Always on top: keeps Syscalculator, WizardExpress and Calculator above other windows.
  • Minimize to tray: hides Syscalculator in the system tray instead of leaving it on the taskbar.
  • Start with Windows: starts Syscalculator automatically when Windows starts.

The tray menu can show Syscalculator, hide it again, open WizardExpress or the Calculator, and exit the program.

Decimals and digit grouping

  • Decimals controls how many decimal places are shown for numeric results.
  • Digit group adds or removes thousands grouping in displayed numbers.

These display settings do not change the converter rule itself. They only control how the result is shown.
