WizardExpress can be used with several applications, but clipboard behavior differs per program.

Works well with

  • plain text programs
  • LibreOffice Calc

For spreadsheet work, plain values without unit symbols are usually the safest result.

Excel / Microsoft 365

Microsoft Excel can handle clipboard data differently from plain text programs and LibreOffice Calc.

  • Excel often uses richer Office clipboard formats.
  • WizardExpress follows the classic clipboard reset and write-back model.
  • Because of that, Excel can behave differently after conversion.
Excel clipboard management: after WizardExpress writes the converted result, paste immediately with Ctrl+V. Avoid right-click paste in Excel, because Excel can replace the converted clipboard data with its own clipboard state. If paste still does not work, copy the values from Excel again and run WizardExpress again.

If paste behavior is difficult in Excel, use one of these routes:

  • try LibreOffice Calc
  • work through files instead of clipboard
  • use normal plain value paste

Excel for the web / Microsoft 365 online can be even stricter because browser clipboard behavior is added on top.

Data and reporting

The advanced WizardExpress window combines data view and debug reporting. The Input and Output tabs show the working data as grids.

Reporting means a compact diagnosis of the clipboard conversion: row and column counts, clipboard formats, the used rule, before/after information, and a short preview.

The report deliberately shows only the first rows when there is a lot of data. That keeps copied, e-mailed, and PDF reports readable. It is a report, not a full data export.
