The updater keeps Syscalculator current without changing your NOD files or personal settings.

Where to find it

  • About > Check for updates... checks immediately.
  • Config > Check for updates automatically controls whether Syscalculator checks at startup.
  • Config > Update channel selects which release line is checked.

Update channels

ChannelPurposeTypical package
DailyFrequent test builds for quick fixes and daily work.Inno Setup installer and updater package.
BetaTest builds for evaluation. A beta can contain unfinished features or regressions and is not meant for everyday production use.MSIX, Inno Setup installer and updater package.
AlphaVery early internal builds. Alpha builds are only for experiments and can break more easily.Only when an alpha test package is published.
ReleaseStable public release line.MSIX and Inno Setup installer.

How an update runs

  1. Syscalculator reads the secure update manifest from Tiedragon.
  2. It compares the package date, version and package identity with the installed build.
  3. When a newer package is available, Syscalculator asks whether you want to download it.
  4. The separate updater downloads the package, checks the SHA-256 value when available, waits for Syscalculator to close, updates the files and starts Syscalculator again.

What the updater does not change

  • It does not edit your NOD converter files.
  • It does not change your language, catalog or converter settings.
  • It does not switch Daily/Beta/Release by itself. The selected channel decides what is checked.

If something goes wrong

  • If there is no internet connection, the update check can fail. Try again later from About > Check for updates....
  • If the checksum does not match, the updater stops. This protects against incomplete or wrong packages.
  • If Syscalculator is still open, the updater waits until it can safely replace the files.
  • If you use the Microsoft Store/MSIX route, Windows may handle installation rules differently from the Inno Setup installer.
Important: Alpha and Beta builds can cause problems because they are test versions. They are not suitable for normal daily use. For normal users, use the Release channel when it is available.
