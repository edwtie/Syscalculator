Geometry, vectors, matrices and statistics

NOD 2.0 math also supports small educational geometry structures. A whole vector or matrix cannot be the final converter result, so convert it to a number with length, distance, dot, det, trace, mget, x, y or z.

Geometry idea: a vector is drawn as an arrow. vec(3,4) is an arrow from (0,0) to (3,4). vec(3,4,12) is an arrow from (0,0,0) to (3,4,12). length(vec(...)) is the length of that arrow.

Example: vector magnitude

Name Vector length
input1 Not used
input2 Length
format #.00
math length(vec(3,4,12))
end

Use math vec (3,4,12) as a shorter form when the result should be the vector-arrow length.

Example: circle equation

Name Circle check
mode geometry
input x X coordinate
input y Y coordinate
math (x-a)^2 + (y-b)^2
end

The circle equation is (x-a)^2 + (y-b)^2 = r^2. If the left side equals r^2, the point lies on the circle.

Example: 2x2 matrix determinant

Name Matrix determinant
input1 Not used
input2 det
format #.00
math det(mat2(1,2,3,4))
end

mat2(a,b,c,d) means the 2x2 matrix with first row a,b and second row c,d.

Example: 3x3 matrix determinant

Name Matrix 3x3
mode matrix3x3
math det(mat3(1,2,3,0,1,4,5,6,0))
end

mat3 stores three rows of three values. Use det, trace, mget or select a vector component with x, y or z.

Example: statistics

Name Dataset mean
input1 Not used
input2 Mean
format #.00
math mean(2,4,4,4,5,5,7,9)
end

Available helpers include sum, mean/avg, median, product, variance, stdev, samplevariance and samplestdev.

Scope: this is a practical NOD 2.0 math layer. Use vector and matrix functions when the final result is a number, such as length, distance, dot, angle, determinant or a selected x/y/z component. Graph 2D can show arrows in the plane; Graph 3D can show X/Y/Z space, points and vector arrows.
