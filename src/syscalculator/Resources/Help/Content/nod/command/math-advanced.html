Vectors, 2x2 matrices and statistics

NOD 2.0 math also supports small educational structures. A whole vector or matrix cannot be the final converter result, so convert it to a number with length, dot, det, trace, mget, x, y or z.

GoalSyntaxExample result
2D vector lengthmath length(vec(3,4))
math vec 3 4		5
3D vector lengthmath length(vec(3,4,12))
math vec (3,4,12)		13
Dot productmath dot(vec(1,2), vec(3,4))11
Angle in degreesmath angled(vec(1,0), vec(0,1))90
Cross product componentmath z(cross(vec(1,0,0), vec(0,1,0)))1
2x2 determinantmath det(mat2(1,2,3,4))
math det2(1,2,3,4)		-2
2x2 trace / cellmath trace(mat2(1,2,3,4))
math mget(mat2(1,2,3,4),2,2)		5 / 4
Matrix times vectormath x(mat2(2,0,0,3) * vec(3,4))6

math stdev(2,4,4,4,5,5,7,9)
math samplestdev(2,4,4,4,5,5,7,9)		5, 4.5, 2, 2.138...

Example: vector magnitude

Name Vector length
input1 Not used
input2 Length
format #.00
math length(vec(3,4,12))
end

Use math vec (3,4,12) as a shorter form when the result should be the vector length.

Example: 2x2 matrix determinant

Name Matrix determinant
input1 Not used
input2 det
format #.00
math det(mat2(1,2,3,4))
end

mat2(a,b,c,d) means the 2x2 matrix with first row a,b and second row c,d.

Example: statistics

Name Dataset mean
input1 Not used
input2 Mean
format #.00
math mean(2,4,4,4,5,5,7,9)
end

Available helpers include sum, mean/avg, median, product, variance, stdev, samplevariance and samplestdev.

Scope: this is a practical NOD 2.0 beta math layer. Use vector and matrix functions only when the final result is a number, such as length, dot, angle, determinant or a selected x/y/z component. Full 3D geometry, 3x3 matrices and graph3D are still future work.
