Probability

NOD 2.0 supports factorial and common probability functions in math.

Factorial

n!=1×2×...×n
ans=n
5!=1×2×3×4×5=120
math ans!

If the input is 5, then ans = 5 and NOD calculates 5!.

Combinations

(nr)=n!r!(n-r)!
ans=n,2=r
(52)=5!2!3!=10
math comb(ans,2)

If the input is 5, then ans = n = 5 and r = 2: choose 2 from 5.

Permutations

P(n,r)=n!(n-r)!
ans=n,2=r
P(5,2)=5!3!=20
math perm(ans,2)

If the input is 5, NOD calculates P(5,2). Use perm(ans,3) for 3 places.

Expected value

E(X)=∑inxi×pi
x1=0,p1=0.5,x2=10,p2=0.5
E(X)=0×0.5+10×0.5=5
math expected(0,0.5,10,0.5)

The function reads pairs: value, probability, value, probability.

GoalSyntaxExample
Factorialmath ans! or math factorial(ans)5! gives 120.
Combinationsmath comb(n,r) or math ncr(n,r)comb(5,2) gives 10.
Permutationsmath perm(n,r) or math npr(n,r)perm(5,2) gives 20.
Expected valuemath expected(value,probability,...)expected(0,0.5,10,0.5) gives 5.
Note: inside functions, commas separate arguments. Use a dot for decimals there, for example 0.5. Outside functions the decimal comma still works, such as math ans / 1,95583.
