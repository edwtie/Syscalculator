phoneformat in NOD 2.0

phoneformat belongs in mode data, inside a field block. The syntax is phoneformat option value.

Important: phoneformat international is not a valid option. Use for example phoneformat country NL and phoneformat normalize_international true.
Basic example 
Name Clean customer phones
mode data
table customers

field phone
phoneformat country NL
phoneformat remove_spaces true
phoneformat remove_text_prefix true
phoneformat normalize_international true
output phone_new
end

This removes text such as tel., removes spaces and converts Dutch international notation such as +31 or 0031 back to a number starting with 0.

All supported options
OptionValueWhat does it do?
countryNLCountry setting. Currently used for Dutch international normalization.
keep_separatortextStored as separator setting.
remove_spacestrue/falseRemoves spaces.
remove_dotstrue/falseRemoves dots.
remove_slashestrue/falseRemoves slashes.
remove_parenthesestrue/falseRemoves parentheses.
remove_text_prefixtrue/falseRemoves text prefixes such as tel. and phone:.
normalize_internationaltrue/falseWith country NL, converts +31 and 0031 to a starting 0.
Combine with chg

In a data field, phoneformat is applied first. After that, rules such as chg, trans or math can work on the cleaned value.

Name Phone renumbering
mode data
table customers

field phone
phoneformat country NL
phoneformat remove_spaces true
phoneformat remove_text_prefix true
phoneformat normalize_international true
chg "01751","07051"
output phone_new
end
