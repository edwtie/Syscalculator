Statistics

NOD 2.0 can calculate common dataset summaries. These functions return one number, so they can be used directly as converter output.

GoalSyntaxExample result
Summath sum(2,4,4,4,5,5,7,9)40
Meanmath mean(2,4,4,4,5,5,7,9)5
Median, M or Memath median(2,4,4,4,5,5,7,9)4.5
Population standard deviationmath stdev(2,4,4,4,5,5,7,9)2
Sample standard deviationmath samplestdev(2,4,4,4,5,5,7,9)2.138...

Example: median notation

Me=4+52=4.5
math median(2,4,4,4,5,5,7,9)

The NOD function is median(...). In Dutch school notation the symbol Me is often used for the median.
