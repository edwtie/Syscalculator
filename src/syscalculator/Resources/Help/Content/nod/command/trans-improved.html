Improved trans: smarter than NOD 1.0

Compatible: classic NOD 1.0 trans still tries exact matches first. NOD 2.0 only then tries a smart compact match.
BehaviorNOD 1.0NOD 2.0Example
Exact value✓✓trans "hallo","hello"
Ignore letter case✕✓Hallo matches hallo
Ignore spaces, dots, dashes and underscore✕✓dank_je, dank je and dank-je can hit the same trans rule
Ambiguous smart match✕✓When two compact matches exist, it does not silently translate wrongly; the input stays unchanged.
