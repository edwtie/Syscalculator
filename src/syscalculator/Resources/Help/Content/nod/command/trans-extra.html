trans examples

trans translates a complete value. It is meant for words, fixed codes, statuses, postcodes, or short lists.

Structure: trans "old value","new value". The complete input must match the left value.
Translate exact text
GoalRuleResult

Translate statustrans "open","in progress"open becomes in progress
Address lookuptrans "2566 GB 241","Nieboerweg 241, 2566 GB Den Haag"postcode + house number becomes address

When trans, when chg?
UseWhenExample
transthe entire input is known exactlyhallo to hello
chgonly the beginning or pattern changes01751-xxxxx to 070-51xxxxx
Common trans mistakes
  • Reversing direction: left is input, right is output.
  • Expecting a partial match. Use chg for that.
  • Using a comma in a value without quotes.
  • Creating duplicate translations for the same input.
