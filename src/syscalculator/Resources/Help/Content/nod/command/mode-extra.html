When do you use mode?

mode tells what kind of NOD file you are making. For normal conversion tools, mode is usually not needed; without mode it works as a normal converter.

Rule of thumb: use mode only when the file has a special type, such as data processing or equation solving.
Common modes
ModeUseImportant commands
mode calculatorNormal converter or calculation helper.math, trans, chg
mode dataProcess rows or fields in a table.table, field, output, phoneformat
mode equationSolve an equation.given, equation, solve, constraint
Example: normal converter
Name Celsius to Fahrenheit
input1 Celsius
input2 Fahrenheit
format #.00
math ans * 1.8
math ans + 32
end

Here mode is not required. This is the default.

Example: data processing
Name Clean customer phones
mode data
table customers

field phone
phoneformat country NL
chg "01751-xxxxx","070-51xxxxx"
output phone_new
end

Use mode data when the NOD file processes table fields.

Example: equation solving
Name Solve equation
mode equation
given y = 20
equation y = x * 2
solve x
constraint x >= 0
end

Use mode equation when you want to solve an unknown variable.
