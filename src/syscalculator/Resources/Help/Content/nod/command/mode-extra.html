When do you use mode?

mode tells what kind of NOD file you are making. For normal conversion tools, mode is usually not needed; without mode it works as a normal converter.

Rule of thumb: use mode only when the file has a special type, such as data processing or equation solving.
Common modes
ModeUseImportant commands
mode calculatorNormal converter or calculation helper.math, trans, chg
mode geometryCoordinate geometry with X/Y/Z inputs, vector arrows, distances, circle equations and Graph 2D/Graph 3D visualization.input x/y/z, math, vec, distance, mat3
mode matrix3x33x3 matrix calculations that end in a number.mat3, det, trace, mget, x/y/z
mode dataProcess rows or fields in a table.table, field, output, phoneformat
mode equationSolve an equation.given, equation, solve, constraint
Example: normal converter
Name Celsius to Fahrenheit
input1 Celsius
input2 Fahrenheit
format #.00
math ans * 1.8
math ans + 32
end

Here mode is not required. This is the default.

Example: data processing
Name Clean customer phones
mode data
table customers

field phone
phoneformat country NL
chg "01751-xxxxx","070-51xxxxx"
output phone_new
end

Use mode data when the NOD file processes table fields.

Example: equation solving
Name Solve equation
mode equation
given y = 20
equation y = x * 2
solve x
constraint x >= 0
end

Use mode equation when you want to solve an unknown variable.

Geometry introduction

mode geometry is the starting point for coordinate geometry in NOD. It is meant for calculations that describe points, vectors, arrows and simple shapes, while Graph 2D and Graph 3D show the same idea visually.

  • input x, input y and input z describe coordinates.
  • vec(x,y) is a 2D vector arrow from the origin to (x,y).
  • vec(x,y,z) is a 3D vector arrow from the origin to (x,y,z).
  • length(vec(...)) gives the length of that arrow.
  • distance(vec(a,b), vec(x,y)) gives the distance between two points.
  • Graph 2D shows X/Y. Graph 3D shows X/Y/Z, camera rotation and depth.
Name Geometry 3D vector
mode geometry
input x X coordinate
input y Y coordinate
input z Z coordinate
math length(vec(3,4,12))
end

The result is 13. Visually, this is the length of the arrow from (0,0,0) to (3,4,12).
