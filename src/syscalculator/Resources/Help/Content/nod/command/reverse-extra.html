When do you use reverse?

reverse is meant for reverse calculation when a formula is not obviously reversible. In NOD 2.0 you can use it to explicitly describe the second direction of a converter.

Rule of thumb: use reverse for compound math rules, parentheses, multiple steps or fixed corrections. For simple one-step calculations it is often not needed.
Basic example: one step back

If the forward direction multiplies, reverse divides back.

Name Meter to centimeter
input1 Meter
input2 Centimeter
format #.00
math ans * 100
reverse ans / 100
end
Reverse multiple math steps

For multiple steps, write the opposite order yourself in one clear reverse rule.

Name Celsius to Fahrenheit
input1 Celsius
input2 Fahrenheit
format #.00
math ans * 1.8
math ans + 32
reverse (ans - 32) / 1.8
end

Forward: first times 1.8, then plus 32. Backward: first minus 32, then divide by 1.8.

Complex formula with parentheses

Use parentheses to show exactly which order belongs to the reverse calculation.

Name Value with correction
input1 Base
input2 Result
format #.00
math ((ans + 10) * 2) / 3
reverse ((ans * 3) / 2) - 10
end
Note: reverse is a calculation rule, not automatic algebra explanation. Always test both directions.
