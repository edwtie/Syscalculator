Math at a glance

math calculates with ans. On the first line ans is the input value; on following lines it is the previous result.

Structure: choose the calculation type first, then write the matching syntax. For larger formulas, use parentheses or multiple lines.

Complex expressions

Use parentheses when order matters. Always write multiplication explicitly with *.

math sqrt(ans^2 + 25)
math ((ans + 10) * 2) / 3
math ans * (1 + 0.04)^5

Example: parentheses

((x+10)×2)3
Name Parentheses example
input1 Value
input2 Result
format #.00
math ((ans + 10) * 2) / 3
end

Example: Pythagoras

c=a2+52
Name Hypotenuse
input1 Side a
input2 Side c

Here ans is side a. The other side is fixed at 5.

Common math mistakes

  • Forgetting ans: write math ans * 100, not math * 100.
  • Putting too much into one line when steps would be clearer.
  • Using sin when you mean degrees. Use sind.
  • Expecting reverse conversion for a complex formula without reverse.
