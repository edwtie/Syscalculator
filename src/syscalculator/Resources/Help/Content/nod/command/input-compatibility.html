Input compatibility in NOD 2.0 beta

Important: old NOD files with input1 and input2 keep working in the 2.x line. For new files, use input for real input and inputr for the reverse/output side.
{WarningBoardSvg}
Avoid collisions: for 2D vectors and limited matrix 2x2, input2 is not supported. Write input x and input y for real values. Use inputr y or output y only for the reverse/output side.

Using input in math

For education and future multi-input NOD, the clear notation is ans(x), ans(y) and ans(height). The short notation ansx, ansy and ansz may be treated as aliases. In NOD 2.0, ans remains the current value/intermediate result and stays compatible with old files.

Status: named inputs can already be read as metadata in the NOD 2.0 beta. Full calculation with multiple input fields belongs to NOD 2.1, so old ans calculations do not break.

input1 and input2 are not broken or forbidden; they are legacy-compatible for normal old converters. For 2D vectors and limited matrix 2x2, input2 is not supported because y or matrix values are real input values. This may become broader and breaking only in NOD 3.0.
