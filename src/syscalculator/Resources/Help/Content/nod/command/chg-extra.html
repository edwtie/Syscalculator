chg examples

chg changes the beginning of text. It is useful for phone numbers, codes, prefixes, and old renumbering tables.

Structure: left is what to find, right is the new form. Use quotes when values contain spaces, commas, or special characters.
Replace a prefix
GoalRuleExample
Old prefix to newchg "01751","07051"0175112345 becomes 0705112345
With dashchg "01751-","070-51"01751-12345 becomes 070-5112345
Longest match winsput specific rules above broad rules01751-9xxxx can be handled separately

Example: The Hague 070

Name Renumbering The Hague
input1 Old phone number
input2 New phone number
chg "01751-xxxxx","070-51xxxxx"
chg "01750-xxxxx","070-50xxxxx"
end

Example: item code

Name Update item code
input1 Old code
input2 New code
chg "OLD-","NEW-"
end
Pattern with x

Use x for characters that must be kept. This is useful for old phone renumbering tables.

chg "050-2xxxxx","050-52xxxxx"

Example: pattern rule

Name Phone pattern
input1 Old
input2 New
chg "050-2xxxxx","050-52xxxxx"
end
Common chg mistakes
  • Putting a broad rule above a specific rule.
  • Forgetting the comma between old and new.
  • Using spaces or commas without quotes.
  • Using chg when you need an exact full-value translation; then use trans.
