NOD 2.0 beta and older NOD files

Syscalculator 2.0 is still beta. New possibilities may still be added, but older NOD 1.x files must keep working.

Compatible: input1, input2, math, trans, chg, Symb1 through Symb4, indoprint, indoend and end stay supported in the 2.x line.
{WarningBoardSvg}
Warning: do not use input2 for 2D vectors or limited matrix 2x2. In those cases y or the matrix value is real input. If input2 is also read as the old reverse/output side, fields can collide and the UI or calculation can link incorrectly or crash.

When to adapt?

  • Let existing old NOD files keep working.
  • For new NOD 2.0 beta files, prefer input x, input y, input text or input phone.
  • Remove input1/input2 only in a real breaking version such as NOD 3.0.

Line integrals and formula cards

Topics such as 2D vector arrows, line integrals and limited matrix 2x2 can already exist in the 2.0 beta as formula cards and educational explanation. A 2D vector may be shown as an arrow in a graph. math geometry, mode geometry and 3x3 matrices are not 2.0 production features yet, because they need a 3D graph/geometry engine. Full calculation with vector fields, paths, 3x3 matrices or 3D belongs to a later advanced NOD layer.
