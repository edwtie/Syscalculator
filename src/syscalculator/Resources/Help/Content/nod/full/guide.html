Workflow

  1. Open an existing .nod file or create a new file with New or Templates.
  2. Write the base lines: Name, input, output, optional symbols and then the calculation rules.
  3. Use command tips and More help when you are unsure about a command.
  4. Use Validate to find syntax errors.
  5. Use Test and the preview to check whether the conversion is correct.
  6. Use Graph 2D for formulas with X/Y behavior, or Graph 3D for a spatial view.
  7. Save only when the converter is correct.

Converter Basics

Name Celsius to Fahrenheit
input1 Celsius
input2 Fahrenheit
format #.00
math ans * 1.8
math ans + 32
end

ans is the current value. On the first math line it is the input value; on later lines it is the previous result.

Choosing Commands

  • Use math for numeric calculations.
  • Use trans for fixed text or value translations.
  • Use chg when mainly the start or a pattern of text must change.
  • Use table, field and output for data converters.
  • Use given, equation and solve for equation files.

Command Tips

The command tip belongs to the line where the caret is placed. It gives short help and can sometimes suggest a modern form. Use Replace only when you really want to adopt that form. Use More help for the full command page.

Validate And Test

  • Validate checks whether the text can be read as NOD.
  • Test runs the converter with a sample value.
  • Formula mistakes are easier to see when you test with several values.
  • In graph files, mistakes often become visible because the line is missing, bends unexpectedly or falls outside the view.

Graph 2D And Graph 3D

Graphs are described separately on the Graph 2D page. It explains X/Y range, Step, table points, lines, locator, rectangle zoom and the Graph 3D controls for 2D, 3D, Top, Z range, Grid and Grid step.

SI And Scale Display

The SI and scale display page describes prefixes such as k, M, n and p, plus extra scale helpers such as lj and IP. This is display only; the backend keeps calculating with plain numbers.

Undo, Redo, Restore And Repair

  • Undo and Redo are about recent text edits.
  • Restore returns the current tab to the last opened or saved version.
  • Repair lines tries to repair pasted or merged NOD lines.

Work Safely

  • Keep old NOD files when making a large change.
  • Use templates to start new files faster and more consistently.
  • Always test both directions when a converter uses reverse behavior.
  • Prefer several clear math lines over one unreadable mega-line.
