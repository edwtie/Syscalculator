What is NOD?

NOD is the text format Syscalculator uses to describe a converter. A NOD file tells the program the converter name, visible input and output labels, symbols near values, and the rules that transform the value.

The basic idea

A NOD file reads like a small recipe. First comes the name, then labels, optional symbols and introduction text, then the rules for calculation or text conversion. The last line is usually end.

Why plain text?

Because the knowledge stays visible. A Celsius/Fahrenheit rule, a euro rate or an old phone renumbering rule is not hidden in program code; it remains readable in the file.

Mini example

Name Celsius to Fahrenheit
input1 Celsius
input2 Fahrenheit
format ##.00
math ans * 1.8
math ans + 32
end

Read this from top to bottom: the converter gets a name, shows two labels, chooses number formatting and runs two calculation steps with ans as the current value.
