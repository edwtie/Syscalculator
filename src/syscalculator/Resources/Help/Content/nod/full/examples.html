Examples by NOD type

NOD files can describe different kinds of converters. Choose the pattern that fits what you want to build.

1. Calculation tool with math

Use this for numbers: temperature, distance, weight, currency, percentage.

Name Celsius to Fahrenheit
input1 Celsius
input2 Fahrenheit
format ##.00
math ans * 1.8
math ans + 32
end

2. Translation tool with trans

Use this when the full input must exactly match a known value. Separate old and new with a comma. Use quotes when values contain spaces or commas.

Name Postcode to address demo
input1 Postcode house number
input2 Address
trans "2566 GB 241","Nieboerweg 241, 2566 GB Den Haag"
end

3. Prefix/pattern tool with chg

Use chg when only the start of the text changes. Separate old and new with a comma. x patterns are allowed, useful for old phone renumbering tables.

Name Operation Decibel example
input1 Old phone number
input2 New phone number
chg "01751-xxxxx","070-51xxxxx"
chg "050-2xxxxx","050-52xxxxx"
end

4. Tool with left/right symbols

Use symbols to display values neatly. Choose left or right per value.

Name German mark to euro
input1 Mark
input2 Euro
Symb1 DM
Symb2 EUR
format ##.00
math ans / 1.95583
end

5. Introduction text with indoprint

Use this when the user should see instructions before using the converter.

indoprint This converter changes Celsius to Fahrenheit.
indoprint Enter a temperature in degrees Celsius.
indoend

6. Equation solving with equation

Use this for formula-like problems where an unknown variable should be solved.

Name Solve equation
given y = 20
equation y = x * 2
solve x
constraint x >= 0
end
