Workflow

  1. Start with Name, input1, and input2; then the converter has a name and visible labels.
  2. Optionally choose symbols with Symb1 through Symb4. Use left or right per value, not both.
  3. Add conversion rules: math for calculations, trans for exact text translation, chg for prefix changes.
  4. Use Validate or F5 to check syntax and Test or F6 to see the result.
  5. Place end at the end.
