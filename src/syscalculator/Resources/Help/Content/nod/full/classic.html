NOD editor introduction

The NOD editor is the workspace for converters. Write code at the top, test input and output below, and use the live preview/simulator on the right to see labels, symbols, introduction text and results.

Classic 1.73 versus NOD 2.0

Syscalculator 1.73 / NOD 1.0Syscalculator 2.0 / NOD editor
Classic text files with Name, input1, input2, math, trans, chg and end.The same base still works, so older NOD files remain recognizable.
You often had to remember where symbols appeared and test in the old calculator.The preview immediately shows Symb1 through Symb4 left or right of the values.
chg was classic prefix replacement, useful for old phone renumbering.Old chg stays compatible; NOD 2.0 adds pattern rules with x capture.
Help mostly came from examples and experience.The editor has suggestions, right-click help, multiple help pages and examples by NOD type.

This table shows which syntax comes from classic NOD files and what was added in NOD 2.0.

What stays the same?

  • Commands are still line-based and readable.
  • end closes the file.
  • A simple converter remains short: name, labels, format and a few rules.

What is new?

  • Live preview and converter simulator.
  • Graph Preview for math-converter graphs.
  • Suggestions while typing.
  • Richer help per command.
  • More examples for math, trans, chg, symbols and indoprint.
