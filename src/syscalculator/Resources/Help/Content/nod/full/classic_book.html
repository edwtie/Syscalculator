Why old and new live together

Syscalculator 2.0 is not a break with old NOD files. The goal is that older converters remain recognizable, while the editor gives more help while writing, testing and maintaining them.

What made classic NOD strong

Classic NOD was small and direct. A math line calculated further with ans. A trans line translated a fixed value. A chg line changed the start of text, for example in old phone renumbering files.

What NOD 2.0 adds

NOD 2.0 keeps that simple base, but surrounds it with a modern editor: syntax coloring, command tips, right-click help, templates, validation, test output, preview and restore. The language stays readable, while the environment helps find mistakes faster.

Rule of thumb

Use old commands when maintaining an existing file. Use the modern form when the editor suggests it and the file becomes clearer. Compatibility matters, but readability is the goal.
