input
input x Label
Meaning: modern input definition for NOD 2.0 beta.
Examples: input x Celsius, input y Width, input height Height, input text Text, input texta Source, input textb Target, input phone Phone number.
Math notation: input x belongs to ans(x)/ansx; custom input such as input height belongs to ans(height) in the NOD 2.1 preparation.
Note: input z is future metadata only; NOD 2.0 does not support a 3D/matrix-3x3 engine.
