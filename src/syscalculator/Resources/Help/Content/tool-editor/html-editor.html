HTML-documenten kun je op twee manieren bewerken.

Source

Source toont de HTML-bron met regelnummers. Gebruik deze stand voor precieze controle, tabellen, links, codeblokken en wanneer je exact wilt zien welke tags in het pakket staan.

Edit

Edit toont de pagina als bewerkbare helptekst. Dit is handig voor gewone tekstwijzigingen. Als je teruggaat naar Source wordt de bewerkte HTML teruggeschreven naar de bron.
